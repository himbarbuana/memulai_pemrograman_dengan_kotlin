## About the Project

This project contains practical exercises covering fundamental and advanced Kotlin concepts.

Main exercises:

- Data Types
- Control Flow
- Collections
- Object-Oriented Programming
- Coroutines

Five optional exercises are also included:

- Sum of Big Three
- Min and Max
- Manipulate String
- Get Middle Characters
- Concat String

## Project Structure

```text
.
├── Exercise 1 - Data Types
├── Exercise 2 - Control Flow
├── Exercise 3 - Collections
├── Exercise 4 - Kotlin OOP
├── Exercise 5 - Coroutines
└── Optional Exercises
```

## Testing

Required exercises:

```bash
./gradlew test --tests ExamTestMain -q
```

Optional exercises:

```bash
./gradlew test --tests ExamTestOptional -q
```

Code style check:

```bash
./gradlew lint
```
