# Proyek Akhir Kotlin

### Data Types → Control Flow → Collections → OOP → Coroutines

Proyek akhir pembelajaran **Kotlin** yang berisi latihan fundamental hingga asynchronous programming.

</div>

---

## Tentang Proyek

Project ini berisi latihan untuk mempelajari konsep dasar dan lanjutan Kotlin melalui praktik langsung.

Latihan utama:

- Data Types
- Control Flow
- Collections
- Object-Oriented Programming
- Coroutines

Tersedia juga lima latihan opsional:

- Sum of Big Three
- Min and Max
- Manipulate String
- Get Middle Characters
- Concat String

## Struktur Project

```text
.
├── Latihan 1 - Tipe Data
├── Latihan 2 - Control Flow
├── Latihan 3 - Collections
├── Latihan 4 - Kotlin OOP
├── Latihan 5 - Coroutines
└── Latihan Opsional
```

## Teknologi

| Technology | Usage |
|---|---|
| Kotlin 1.9.0 | Programming language |
| Gradle 8.3 | Build system |
| IntelliJ IDEA | Development environment |
| Ktlint | Code style checking |

## Testing

Latihan wajib:

```bash
./gradlew test --tests ExamTestMain -q
```

Latihan opsional:

```bash
./gradlew test --tests ExamTestOptional -q
```

Pemeriksaan kode:

```bash
./gradlew lint
```

## Catatan

Project ini dibuat sebagai **submission pembelajaran Kotlin**, dengan fokus pada pemahaman fundamental Kotlin, OOP, Collections, dan Coroutines.
